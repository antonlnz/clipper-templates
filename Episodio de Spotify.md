# Episodio de Spotify

[[Plantillas Clipper|← Catálogo]]

Para episodios de podcast en Spotify (`/episode/`). Guarda título, programa, portada y descripción. Van a [[Categorías/Podcasts]] con las mismas propiedades que los de Apple Podcasts. Si la descripción aparece recortada con «Mostrar más», despliégala antes de capturar.

## Archivo importable

[[Sistema/Clipper/JSON/Episodio de Spotify.json|Abrir el JSON]]

En Web Clipper → Ajustes → Plantillas → Importar, selecciona este archivo. Si editas la versión del navegador, expórtala para actualizar esta copia.
