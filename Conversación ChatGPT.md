# Conversación ChatGPT

[[Plantillas Clipper|← Catálogo]]

Captura conversaciones de chatgpt.com (`/c/` y `/share/`) con el extractor de conversaciones integrado en Web Clipper. Cada mensaje queda marcado como el rótulo que muestre ChatGPT (por ejemplo **Tú dijiste** o **You said**), separado por una línea.
