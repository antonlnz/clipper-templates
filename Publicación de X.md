# Publicación de X

[[Plantillas Clipper|← Catálogo]]

Para posts de X (`/status/`). Usa el extractor de X integrado en Web Clipper. Si el autor ha continuado su post con respuestas propias seguidas (un hilo), todas quedan juntas en «Publicación», separadas por una línea. Las respuestas de otras personas se guardan aparte en un desplegable «Respuestas». Si el post es un artículo de X, lo detecta y lo guarda como artículo (ver [[Sistema/Clipper/Fichas/Artículo de X|Artículo de X]]). Para perfiles usa [[Sistema/Clipper/Fichas/Perfil de X|Perfil de X]].

## Archivo importable

[[Sistema/Clipper/JSON/Publicación de X.json|Abrir el JSON]]

En Web Clipper → Ajustes → Plantillas → Importar, selecciona este archivo. Si editas la versión del navegador, expórtala para actualizar esta copia.
