# Sci-Hub

[[Plantillas Clipper|← Catálogo]]

Para artículos en Sci-Hub y sus espejos (cualquier dominio que contenga `sci-hub`, seguido de un DOI). Guarda título, autores, año, la referencia completa, el DOI con su enlace a doi.org y el enlace al PDF. Van a [[Categorías/Papers]]. Para Sci-Net usa [[Sistema/Clipper/Fichas/Sci-Net|Sci-Net]].

## Archivo importable

[[Sistema/Clipper/JSON/Sci-Hub.json|Abrir el JSON]]

En Web Clipper → Ajustes → Plantillas → Importar, selecciona este archivo. Si editas la versión del navegador, expórtala para actualizar esta copia.
