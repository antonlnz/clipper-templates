# Conversación Claude

[[Plantillas Clipper|← Catálogo]]

Captura conversaciones de claude.ai (`/chat/` y `/share/`) con el extractor de conversaciones integrado en Web Clipper. Cada mensaje queda marcado como el rótulo del extractor de Clipper (**You** o **Claude**), separado por una línea.

## Archivo importable

[[Sistema/Clipper/JSON/Conversación Claude.json|Abrir el JSON]]
