# FilmAffinity

[[Plantillas Clipper|← Catálogo]]

Para fichas de FilmAffinity (`/film….html`). Guarda título, título original, año, duración, dirección, los ocho primeros actores, género, nota media, póster y sinopsis. Detecta las series por la etiqueta «Serie de TV» y las manda a [[Categorías/Series]]; el resto, a [[Categorías/Películas]].

## Archivo importable

[[Sistema/Clipper/JSON/FilmAffinity.json|Abrir el JSON]]

En Web Clipper → Ajustes → Plantillas → Importar, selecciona este archivo. Si editas la versión del navegador, expórtala para actualizar esta copia.
