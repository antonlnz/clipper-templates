# Perfil de X

[[Plantillas Clipper|← Catálogo]]

Para perfiles de X (`x.com/usuario`); se activa sola en la página de un perfil. Crea una ficha en [[Categorías/Cuentas]] con nombre, @usuario, biografía, avatar y portada; con sesión iniciada añade ubicación, web, fecha de alta y seguidores. Para posts usa [[Sistema/Clipper/Fichas/Publicación de X|Publicación de X]].

## Archivo importable

[[Sistema/Clipper/JSON/Perfil de X.json|Abrir el JSON]]

En Web Clipper → Ajustes → Plantillas → Importar, selecciona este archivo. Si editas la versión del navegador, expórtala para actualizar esta copia.
